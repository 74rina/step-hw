# 最長経路を求める

- Beam Search

- 枝刈り

を使って、target_depth を超えるまで経路探索を行う。

## ポイント

- 全ての経路を探索するのではなく、「長い経路につながりそうなノード」を優先して探索する。

- ゴールに到達不可能なノードは、探索しない（枝刈り）。

## 1. 次の探索候補から「長い経路につながりそうなノード」を選ぶ

- 「経路のスコア」（＝ゴールまで遠い度）を次のように定義する。

```
score(経路) = 経路の総ノード数 + a * (現在ノードからゴールまでの最短距離) + b * (現在ノードから出る辺の本数)

（a, bは定数）
```

- 「経路のスコア」上位 k 個のノードを、次の探索対象にする（探索幅を k 個とする、幅制限探索）。

## 2. ゴールに到達不可能なノードは探索しない

- グラフの全ての辺を逆向きにする（links の辞書を逆引きして、reverse_links の辞書を作る）。

- reverse_links を用いてゴールからBFSを行い、「ゴールに到達可能なノード・その距離」の辞書 dist_to_goal を作る。

（3時間で長さ7,000に到達したので、160,000は授業に間に合いません、、、😭）
